# Erinnerungs-System

## Was macht dieses Feature?

Erinnert per E-Mail, wenn längere Zeit kein neuer Tagebuch-Eintrag veröffentlicht wurde. Hilft dabei, die Website regelmässig mit frischem Inhalt zu pflegen.

**Phase 2** — noch nicht aktiviert.

## Aktivierung

In `ai-tools/config.yaml`:

```yaml
reminder:
  enabled: true
```
