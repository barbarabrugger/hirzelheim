# Redaktionshandbuch — Hirzelheim-Website

**Für:** Mitarbeitende des Hirzelheims
**Stand:** März 2026

---

## Einführung

Diese Anleitung erklärt, wie Sie Inhalte auf der Hirzelheim-Website bearbeiten können. Sie brauchen dafür **keine technischen Kenntnisse** — alles geht über eine einfache Web-Oberfläche.

## Anmelden

1. Öffnen Sie im Browser: **https://hirzelheim.ch/admin/**
2. Melden Sie sich mit Ihrem Konto an
3. Sie sehen nun die Verwaltungsoberfläche

## Einen Tagebuch-Eintrag erstellen

So erzählen Sie, was im Hirzelheim läuft:

### Schritt 1: Neuen Eintrag anlegen

1. Klicken Sie links auf **«Tagebuch»**
2. Klicken Sie auf **«Neuer Tagebuch-Eintrag»**

<!-- Screenshot-Platzhalter: Tagebuch-Übersicht -->

### Schritt 2: Inhalt eingeben

1. **Titel**: Ein kurzer, ansprechender Titel (z. B. «Frühlingsfest im Garten»)
2. **Datum**: Wird automatisch auf heute gesetzt — bei Bedarf ändern
3. **Kurzbeschreibung**: 1–2 Sätze, die den Beitrag zusammenfassen
4. **Kategorie**: Wählen Sie passende Kategorien (Feste, Ausflüge, Alltag, etc.)
5. **Inhalt**: Schreiben Sie Ihren Text. Sie können Text fett oder kursiv formatieren und Zwischentitel setzen.

<!-- Screenshot-Platzhalter: Eintrag bearbeiten -->

### Schritt 3: Foto hinzufügen (optional)

1. Klicken Sie bei **«Titelbild»** auf **«Bild auswählen»**
2. Laden Sie ein Foto hoch (max. 5 MB)
3. Geben Sie eine **Bildunterschrift** ein (wichtig für Barrierefreiheit!)

**Tipp zur Fotogrösse:** Ideal sind Fotos mit einer Breite von ca. 1200–1920 Pixeln. Die meisten Smartphone-Fotos funktionieren direkt.

**Wichtig:** Keine Fotos von Bewohnenden veröffentlichen, ohne deren ausdrückliche Einwilligung!

### Schritt 4: Veröffentlichen

1. Prüfen Sie den Beitrag in der Vorschau
2. Klicken Sie auf **«Veröffentlichen»**
3. Der Beitrag erscheint nach wenigen Minuten auf der Website

## Eine Stellenanzeige erstellen

### Schritt 1: Neue Stelle anlegen

1. Klicken Sie links auf **«Stellenanzeigen»**
2. Klicken Sie auf **«Neue Stellenanzeige»**

### Schritt 2: Informationen eingeben

1. **Stellenbezeichnung**: z. B. «Pflegefachperson HF/FH»
2. **Pensum**: z. B. «60–80%»
3. **Stellenantritt**: z. B. «per sofort» oder «1. August 2026»
4. **Kontaktperson**: Wer Bewerbungen entgegennimmt
5. **Stellenbeschreibung**: Aufgaben, Profil, Was wir bieten

### Schritt 3: Entwurf oder veröffentlichen

- Setzen Sie **«Entwurf»** auf aktiv, wenn die Stelle noch nicht veröffentlicht werden soll
- Klicken Sie auf **«Veröffentlichen»**, wenn alles bereit ist

### Stelle entfernen

Wenn eine Stelle besetzt ist, können Sie den Eintrag löschen oder als Entwurf markieren.

## Seiteninhalte bearbeiten

Unter **«Seiten»** können Sie den Text der Hauptseiten bearbeiten:

- Startseite (Hero-Text, Untertitel)
- Über uns
- Leben im Heim
- Stiftung
- Kontakt

**Tipp:** Ändern Sie nur, was nötig ist. Die Grundstruktur und das Design bleiben automatisch erhalten.

## Fotos hochladen — Tipps

| Thema | Empfehlung |
|-------|------------|
| Format | JPG oder PNG |
| Grösse | Max. 5 MB pro Bild |
| Auflösung | 1200–1920 Pixel breit |
| Inhalt | Kein Foto von Bewohnenden ohne Einwilligung |
| Beschreibung | Immer eine Bildunterschrift eingeben |

## Checkliste vor dem Veröffentlichen

Bevor Sie auf «Veröffentlichen» klicken:

- [ ] Titel ist aussagekräftig und korrekt
- [ ] Text enthält keine Tippfehler
- [ ] Keine Namen von Bewohnenden ohne deren Einwilligung
- [ ] Foto hat eine Bildunterschrift
- [ ] Foto zeigt keine erkennbaren Bewohnenden (ohne Einwilligung)
- [ ] Datum ist korrekt

## Jährlicher Content-Kalender (Vorschlag)

Damit die Website lebendig bleibt, hier ein Vorschlag für regelmässige Beiträge:

| Monat | Mögliche Themen |
|-------|-----------------|
| Januar | Neujahrsgrüsse, Winterimpressionen |
| Februar | Fasnacht, Kreativnachmittag |
| März | Frühlingsbeginn, Gartenarbeit |
| April | Ostern, Osterbrunch |
| Mai | Muttertag, Ausflug |
| Juni | Sommerfest, Gartensaison |
| Juli | Sommeraktivitäten, Grillabend |
| August | Bundesfeier, Sommerausflug |
| September | Herbstbeginn, Erntedank |
| Oktober | Herbstspaziergang, Bastelnachmittag |
| November | Räbeliechtli, Adventsvorbereitungen |
| Dezember | Adventsfeier, Weihnachten, Jahresrückblick |

**Ziel:** Mindestens **ein Beitrag pro Monat** hält die Website lebendig und zeigt Angehörigen, dass im Hirzelheim etwas läuft.
